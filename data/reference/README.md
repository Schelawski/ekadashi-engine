# Referenzdaten

`astronomy/swetest-2.10.03.json` enthält feste astronomische Vergleichswerte aus
Astrodiensts nativem Referenzprogramm, einschließlich Befehlen und Herkunft.
Details und Toleranzen: [Astronomie](../../docs/astronomy.md).

Offizielle religiöse Kalenderdaten werden später mit Quelle, Ort, Jahr und
Tradition ergänzt. Die astronomischen Testfälle sind keine bestätigten Fastentage.
